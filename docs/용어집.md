# 용어집 (한국어 → 영어)

영어 번역(`I18N_EN`)에서 끝까지 같은 말을 쓰기 위한 표. 새 문구를 추가하거나 고칠 때도 여기 표기를 따른다. 문체는 1차 대전 참호전풍의 짧은 군사 영어, 지시문은 2인칭 명령형("Pick a node…").

## 문체 규칙

- 버튼·탭·병과 이름은 짧게(휴대폰 화면에서 넘치지 않게).
- 한국어의 정중한 안내는 평서·명령형으로("고르세요" → "Pick…").
- 숫자 뒤 단수/복수에 주의하고, 어색하면 `×{0}` 같은 짧은 꼴을 쓴다.
- `{0}`·태그는 개수와 번호를 그대로 둔다(위치는 영어 어순에 맞게 옮겨도 된다).
- 큰따옴표 대신 ‘ ’ 또는 작은따옴표를 쓴다.
