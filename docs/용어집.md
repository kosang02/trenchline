# 용어집 (한국어 → 영어)

영어 번역(`I18N_EN`)에서 끝까지 같은 말을 쓰기 위한 표. 새 문구를 추가하거나 고칠 때도 여기 표기를 따른다. 문체는 1차 대전 참호전풍의 짧은 군사 영어, 지시문은 2인칭 명령형("Pick a node…").

## 핵심 용어

| 한국어 | 영어 | 메모 |
|---|---|---|
| 참호전선 | Trench Line | 게임 이름 |
| 작전 | Operation | 한 판(런). 짧게 "Op" 가능 |
| 전선 | Front | "{0}번째 전선" = "Front {0}" |
| 전투 | Battle | 지도 노드 이름 |
| 정예 | Elite | 지도 노드·적 부대 |
| 휴식 | Rest | 지도 노드 |
| 보급 | Supply | **지도 화폐**. 전투 중 주기 지급은 "supply drop" |
| 보급 주기 | Supply interval | |
| CP | CP | 전투 중 화폐. 풀어 쓰지 않는다 |
| 공적 | Merit | 영구 강화 화폐 |
| 사령부 | HQ | 사령부 내구도 = "HQ HP", 전차 내구도 = "tank HP" |
| 사령부 보급창 | HQ Depot | 영구 강화 상점 |
| 후방 보급소 | Rear Depot | 작전 중 보급으로 사는 곳 |
| 유물 | Relic | |

| 특성 | Perk | |
| 지원 카드 | Support Card | |
| 출신 | Background | 지휘관 선택 |
| 등급 | Rank | 작전 난이도 단계 |
| 계승 | Carry over | 다음 작전에 가져감 |
| 전진 / 사수 / 후퇴 | Advance / Hold / Fall Back | 부대 지시 |
| 참호 | trench | |
| 무인지대 | no man's land | |

## 문체 규칙

- 버튼·탭·병과 이름은 짧게(휴대폰 화면에서 넘치지 않게).
- 한국어의 정중한 안내는 평서·명령형으로("고르세요" → "Pick…").
- 숫자 뒤 단수/복수에 주의하고, 어색하면 `×{0}` 같은 짧은 꼴을 쓴다.
- `{0}`·태그는 개수와 번호를 그대로 둔다(위치는 영어 어순에 맞게 옮겨도 된다).
- 큰따옴표 대신 ‘ ’ 또는 작은따옴표를 쓴다.
